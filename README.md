# AIST-AI Site Tunnel
Приложение для получения доступа к AI сайтам без VPN (Windows версия)<br>
Работает путём переписывания файла hosts (делает бэкап), добавляя адреса сайтов с другими геоданными (DNS дальше от РФ)<br>
Даёт **доступ без VPN** к таким сайт как:<br>
<br>ChatGPT
<br>Grok
<br>Canva
<br>Anthropic...
