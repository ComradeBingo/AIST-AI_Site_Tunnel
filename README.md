# AIST-AI Site Tunnel
Приложение для получения доступа к AI сайтам без VPN (Windows версия)
Работает путём переписывания файла hosts (делает бэкап), добавляя адреса сайтов с другими геоданными (DNS дальше от РФ)
Даёт доступ без VPN к таким сайт как:
ChatGPT
Grok
Canva
Anthropic...
